# Иллюстрации: конвейер подготовки

Все команды выполняются из `app/`. Нужны Node 22 и `sharp` (devDependency). Перекраска и обработка работают без сети и ключей.

## Порядок

1. **Базы** (24 персонажа: 13 архетипов, герой-«загадка», 10 NPC) сгенерированы `gpt-image-1` по единому стилевому промпту — см. `manifest.json`. Генератор `generate.mjs` нужен только для новых баз; он читает ключ из переменной окружения `OPENAI_API_KEY`, не импортируется приложением и не запускается в тестах и сборке.
2. **Постобработка** баз — `process.mjs` (алгоритмы в `pixels.mjs`): очистка почти прозрачного шума, удаление тени под ногами, заливка прозрачных «дырок» в значке BI, удаление оторванных кусков, обрезка.
3. **Локальная перекраска касок** — `recolor.mjs` (алгоритм в `local-color.mjs`): маска каски по цвету и форме (поле каски — самая широкая полоса, всё ниже отсекается), затем смена оттенка с сохранением светотени, блика и значка. Альфа-канал не меняется. Профиль `orange` — 12 архетипов и «загадка», `blue` — лис-«Универсал» (его мех совпадает по оттенку с оранжевой каской, поэтому база лиса — в синей каске).
4. **Кодирование** — `encode.mjs`: портрет 600×900 с выравниванием вниз и аватар 256×256, WebP quality 86.

```bash
node scripts/art/process.mjs --stage base
node scripts/art/recolor.mjs
node scripts/art/sheet.mjs --sheet all
```

Перекрашенные изображения повторно через `process.mjs` не пропускаются: их альфа должна совпадать с базой.

## Проверки

- `src/tests/localArt.test.ts` — все 84 перекраски: альфа идентична базе, вне маски нет изменений, маска занимает 10–35% персонажа и лежит в верхних 45%; эталонные хеши RGBA и WebP.
- `src/tests/art.test.ts` — наличие всех 188 публичных файлов и общий бюджет 12 МиБ.
- `src/tests/fixtures/art-bases` — 14 обработанных баз, чтобы тесты перекраски работали без внешних файлов.

## Листы для просмотра

```bash
node scripts/art/sheet.mjs --sheet base
node scripts/art/sheet.mjs --sheet archetypes
node scripts/art/sheet.mjs --sheet npc
node scripts/art/sheet.mjs --sheet avatars
node scripts/art/sheet.mjs --sheet all
```

Каждый лист создаётся на клетчатой подложке и на тёмно-синем фоне `#142036` — на тёмном видны прозрачные участки, тени и дырки. Параметры: `--background checker|dark`, `--source raw`.

Сырые генерации и рабочие папки (`../art/raw`, `../art/processed`, `../art/local`, `../art/review`) находятся вне репозитория. В репозитории — только готовые WebP в `public/art/`.
